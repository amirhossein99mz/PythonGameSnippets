NEAREST WORD PAIRS

The file worms.txt contains an unknown number of sequences; each sequence is a line with an unknown number of words. A word may appear multiple times within the same sequence and across different sequences.

Write a Python program that asks the user for two words and reports which sequence (line number) contains the smallest distance between any occurrence of those two words. Print the sequence number (1-based) and the distance.
If the two words never occur together in any sequence, print a warning message.
